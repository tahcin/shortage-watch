# Brief 01b: make the sample formulary look like a real hospital's

Review of the first `products.json` found picks a pharmacist would reject. Fix `scripts/build-sample-hospital.ts` and regenerate `seed.sql` and `products.json`.

1. **Single-ingredient products only**, unless the generic name itself names a combination. Use the openFDA `active_ingredients` array length. Examples of current mistakes: "dextrose" picked a potassium chloride + dextrose bag; "bupivacaine" picked bupivacaine with epinephrine.
2. **Manufacturers, not repackagers or relabelers.** Skip labelers whose name matches a deny list (A-S Medication Solutions, HF Acquisition / HealthFirst, ProPharma Distribution, Henry Schein, Medical Purchasing Solutions, General Injectables and Vaccines, Cardinal Health 107, NuCare, Proficient Rx, Quality Care Products, RemedyRepack, Asclemed / Enovachem, Fagron, Direct_Rx, Bryant Ranch Prepack, PD-Rx, Preferred Pharmaceuticals) and any labeler containing "repack", "relabel", "medication solutions", "distribution". Prefer `marketing_category` ANDA or NDA.
3. **Hospital presentations:** prefer vials, ampules, prefilled syringes and premix bags over auto-injectors or kits. For epinephrine pick 1 mg/mL; for dextrose pick 50% (500 mg/mL) syringes or vials; for heparin pick 5,000 units/mL; for potassium chloride pick a concentrate or premix bag; for amoxicillin keep oral suspension; for albuterol keep the inhalation solution.
4. **Tie about a third of items to the real FDA shortage list.** Before choosing, fetch the current shortage list once (`https://api.fda.gov/drug/shortages.json?search=status:"Current"&limit=1000` and `&skip=1000`, cache it). For a generic name that appears there, prefer a package NDC that is on that list (so "our supplier's product is short" is true in the real data). For the rest, pick a major manufacturer's product. Record in `products.json` whether the chosen package was on the shortage list at build time (`onShortageListAtBuild: true/false`, with the availability text).
5. **Therapeutic class:** fill `therapeutic_class` from `pharm_class` (prefer the `[EPC]` entry); if empty, use the shortage list's `therapeutic_category`; otherwise leave empty.
6. Store `application_number` (for example `ANDA090850`) per product in `products.json` and add a column `application_number text` to `formulary` (schema and seed). It links to the FDA Orange Book.
7. Keep the seed (20261022), the SAMPLE DATA header and the caching. Days of cover: make sure at least 6 items that are on the shortage list have under 10 days of cover, and a few non-short items have under 10 days too (so the agent has to tell supply risk from ordinary low stock).

Run `npm run typecheck` and `npm run build-sample`, then print a table: generic name, labeler, strength, dosage form, on shortage list (yes/no), days of cover.
